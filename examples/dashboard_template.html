FieldGuard

Schema-forced decoding guarantees structure, not truth. Every field is extracted twice — once under the schema, once free-form — and only the fields where those paths disagree are ever re-verified.

Pipeline

The selected field's actual journey, stage by stage. Two stages carry the method's novelty: disagreement compares the two paths against each other, grounding compares the kept value against the source. They fail independently, which is why both exist.

SIGNAL 1 catches corruption the constraint caused SIGNAL 2 catches values the document never supported Stages 6–7 run only when a field is flagged — that is the saving
